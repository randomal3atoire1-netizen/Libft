Description :
This project's name is Libft, it's a library of functions in C for future projects.

Instructions :
You can create the library "libft.a" with the command "make" at the root of the directory

Resources :
There's no use of the IA for this project, a programm named "Libfterator" has been used for the debug phase.

Here is the list of the functions in the library :
- ft_atoi : reproduce atoi from stdlib
- ft_bzero : reproduce bzero from string
- ft_calloc : reproduce calloc from stdlib
